# Isolated Kubernetes acceptance test

The `isolated-kubernetes` CI job creates a disposable kind cluster on a GitHub-hosted runner. The test obtains a fresh kubeconfig from the named kind cluster and checks its node label before changing resources. It creates two test namespaces and fixture pods, installs the chart, and loads a locally built image into the cluster. The fixture credentials and log markers are synthetic.

The script checks that the service account can read allowed pods but cannot read secrets, create pods, or list pods in a denied namespace. It checks anonymous denial, namespace policy, bounded current logs and untrusted text, unavailable previous logs, and previous logs after a fixture container restarts. It uninstalls the release and verifies its Service, Role and RoleBinding were removed. The expanded test also installs the explicit all-namespaces mode, checks access to an existing and a newly created namespace, denies Secrets and writes, and verifies removal of the ClusterRole and binding. A separate deployment exercises origin TLS with a synthetic certificate. The test does not exercise Cloudflare, external clients, production traffic, or network policies.

The script refuses to run unless `GITHUB_ACTIONS=true` and the dedicated single-node kind cluster exists. Do not point it at a shared or production cluster. The namespace-scoped and all-namespaces checks passed in CI at `a990e68`, and the origin TLS deployment test passed at `785e983`. The kind job checks each running pod's image identity against the build's manifest or configuration digest. A configuration-digest match establishes the same configuration and uncompressed layers, not necessarily identical compressed manifest bytes. The staging job compares build metadata, scans the image, and checks a quarantine registry digest before publishing the staging tag. A failed job may leave the quarantine tag in the registry. The digest-link checks passed in CI at `36bbe98`. This is isolated-cluster evidence, not a production deployment or a complete acceptance result.
